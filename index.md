Critical Coding collects small, self-contained code samples from the course at the Zurich University of the Arts (ZHdK). Every example is its own repository in the ZHdK-Critical-Coding organisation on GitHub and shows one technique: reading data from a sensor, a camera, the web or an AI model (input), processing pixels, type, numbers and simulations (transformation), or sending results to screens, LEDs, printers and files (output). Open an example to read its documentation, then clone the repository to run and modify it.
