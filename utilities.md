<div class="lang" lang="en" markdown="1">

Utilities are the helpers the code samples rely on: servers that relay messages or drive hardware, Arduino sketches that turn buttons and sensors into input for the computer, and editor extensions that help while writing code.

Each code sample that needs one of them links to it under *Related*.

</div>

<div class="lang" lang="de" markdown="1">

Werkzeuge sind die Helfer, auf die die Code-Beispiele angewiesen sind: Server, die Nachrichten weiterleiten oder Hardware ansteuern, Arduino-Sketches, die Taster und Sensoren zu Eingaben für den Computer machen, und Editor-Erweiterungen, die beim Schreiben von Code helfen.

Jedes Code-Beispiel, das eines davon braucht, verlinkt es unter *Related*.

</div>
