# P5 -> Infotag

A small tool to create animated text tags: layers with growing, alternating
black/white outlines are stacked on top of the text. Speed and interval can be
adjusted, and one iteration can be exported as GIF (`saveGif`).

## How to Use

1. Start Live Server (click **Go Live** in the VS Code status bar).
2. Enter a text and press **UPDATE**.
3. Adjust **Speed** and **Interval**.
4. Press **EXPORT one Iteration as GIF** to download the animation.
