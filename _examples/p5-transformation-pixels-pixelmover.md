# P5.js: Pixelmover

Samples the pixels of `assets/150.jpg` on a grid and turns each one into a
particle.

## How to Use

1. Start Live Server (click **Go Live** in the VS Code status bar).
2. Click on the canvas to let the pixels fall down.
