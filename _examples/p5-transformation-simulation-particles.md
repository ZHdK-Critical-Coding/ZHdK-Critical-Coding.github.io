# P5.js: Particles

A simple particle system: every frame a new particle (a random letter of
"ZHDK") is emitted with a random force and mass, pulled by gravity and removed
when it leaves the canvas. The `Particle` class lives in `particle.js`.

See also: [Nature of Code – Particles](https://natureofcode.com/particles/)

1. Start Live Server (click **Go Live** in the VS Code status bar).
