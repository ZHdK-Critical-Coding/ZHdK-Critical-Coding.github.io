# P5 -> Physics

Letters as physical bodies using [matter.js](https://brm.io/matter-js/). The
glyph outline of each typed character is converted to points
(`font.textToPoints`) and used as a matter.js body that falls onto two static
circular boundaries. Based on examples from
[The Nature of Code](https://natureofcode.com/physics-libraries/).

## How to Use

1. Start Live Server (click **Go Live** in the VS Code status bar).
2. Type any key to drop that letter into the scene.
