# P5 -> Trigonometrie

Visualises `sin()`, `cos()` and `tan()` as animated dots with fading trails
running across the screen. Each curve is an instance of a small
`trigonometryCurve` class (frequency, trail size, speed and dot size are
configurable).

## How to Use

1. Start Live Server (click **Go Live** in the VS Code status bar).
