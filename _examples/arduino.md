# Arduino: Keyboard Button

### Arduino Keyborard Emulation

This sketch emulates a keyboard. Without changing, it sends a Keystroke like "ENTER" if the i/o pin 2 is connected to GND.

Works with all Arduinos which support the keyboard library.
