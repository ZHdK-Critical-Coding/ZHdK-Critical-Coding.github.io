<div class="lang" lang="en" markdown="1">

Document generation means producing layouts with code instead of by hand: a template describes the design once, and a script fills it with texts and images – for one document or for hundreds.

Batch mode examples read a folder of source material and turn it into a document: placing a folder of images in InDesign, or combining texts and images into one PDF. The same task is solved with different tools: InDesign with basil.js, Typst, LaTeX and HTML/CSS.

</div>

<div class="lang" lang="de" markdown="1">

Dokumente erzeugen heisst, Layouts mit Code statt von Hand herzustellen: Eine Vorlage beschreibt die Gestaltung einmal, und ein Script füllt sie mit Texten und Bildern – für ein Dokument oder für hunderte.

Die Beispiele im Stapelbetrieb (Batch Mode) lesen einen Ordner mit Ausgangsmaterial und machen daraus ein Dokument: einen Ordner mit Bildern in InDesign platzieren oder Texte und Bilder zu einem PDF zusammenfügen. Dieselbe Aufgabe wird mit verschiedenen Werkzeugen gelöst: InDesign mit basil.js, Typst, LaTeX und HTML/CSS.

</div>
